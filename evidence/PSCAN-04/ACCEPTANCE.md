# PSCAN-04 Acceptance Evidence

## Result

`ACCEPT`. PSCAN-04 satisfies its activated bounded internal artifact,
redaction, cleanup and network-disabled execution scope. Acceptance is local,
evidence-based and limited to PSCAN-04. No successor is selected or activated.

## Accepted implementation

- Deterministic private snapshots normalize directories, ZIP, TAR, gzip/TGZ,
  OCI Image Layout 1.1.1's documented image subset and strict legacy/current
  Docker-save inputs without candidate execution.
- Traversal, absolute/drive/ADS paths, unsafe links, reparse points, devices,
  hard links, duplicate/case-colliding paths, encryption, malformed framing,
  unsupported formats and bombs fail closed.
- Exact nesting, entry, expanded-byte, individual-file, compression-ratio,
  timeout, memory and process boundaries are declared and adversarially tested.
- Redaction precedes every exposed diagnostic path and rejects raw, partial,
  encoded, hashed, fingerprint, path/location, detector/provider, Git and
  allowlist disclosure.
- Authoritative execution is digest-pinned, network-disabled, credential-free,
  read-only, capability-dropped, no-new-privileges and resource-bounded.

## Limitations and owner gates

The public runner is outside PSCAN-04's allowed paths and remains unavailable.
This acceptance does not establish consumer, deployment, production,
Windows-runtime or complete cross-platform readiness, nor support beyond the
documented strict OCI/Docker subset. No remote, push, publication, release,
signing, spending, credential, GitHub-setting, TruffleHog, provider,
consumer-project, deployment, legal, production or go-live action occurred.
All such gates remain owner-controlled, and acceptance creates no successor
authority.
